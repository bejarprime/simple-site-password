# Ideas de contenido LinkedIn - Simple Site Password

## Ángulos posibles

- Lo difícil de un plugin aparentemente simple.
- Por qué no se debe guardar una contraseña en texto plano.
- Cómo evitar bloquear `wp-login.php`.
- Diferencia entre protección simple y seguridad real.
- Uso responsable de cookies.
- Cómo diseñar un MVP pequeño pero completo.
- Qué revisaría WordPress.org en un plugin así.

## Posibles posts

### Post técnico 1

Tema: Excepciones necesarias para no romper WordPress.

Idea:

> Proteger todo un sitio suena fácil hasta que recuerdas que WordPress necesita rutas que no puedes bloquear: login, admin, AJAX, REST y cron.

### Post técnico 2

Tema: Contraseña hasheada.

Idea:

> Aunque sea una contraseña global simple, no tiene sentido guardarla en texto plano. WordPress ya trae funciones para hashear y verificar contraseñas.

### Post final

Tema: Demo y aprendizajes.

Idea:

> Primer plugin terminado: protección global por contraseña para WordPress. Pequeño, pero con decisiones importantes de seguridad y UX.
