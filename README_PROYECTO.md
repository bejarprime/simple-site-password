# Simple Site Password

Primer plugin de la serie de plugins WordPress open source.

## Objetivo

Crear un plugin sencillo para proteger un sitio WordPress completo con una contraseña global.

El visitante verá una pantalla de acceso antes de poder navegar por el sitio. Una vez introducida la contraseña correcta, se guardará una cookie temporal para recordar el acceso.

## Enfoque

Este plugin prioriza:

- simplicidad,
- seguridad básica,
- buen uso de APIs de WordPress,
- documentación,
- claridad para usuarios no técnicos,
- publicabilidad en WordPress.org.

## Qué NO es

No es:

- un plugin de membresías,
- un firewall,
- una solución de seguridad avanzada,
- un sistema de usuarios,
- un sustituto de autenticación real para información altamente sensible.

## Valor para portfolio

Este plugin permite demostrar:

- creación de página de ajustes,
- uso de hooks,
- control de flujo frontend,
- formularios seguros,
- nonces,
- sanitización,
- escaping,
- cookies,
- documentación,
- comunicación técnica en LinkedIn.
