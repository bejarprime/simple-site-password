Protect your WordPress site with a simple global password for visitors.

== Description ==

Simple Site Password lets you protect an entire WordPress site with a global password.

It is designed for simple use cases such as development sites, private client previews, pre-launch landing pages or temporary private websites.

This plugin is not a replacement for a membership system, firewall or advanced authentication solution.

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`.
2. Activate the plugin from the Plugins screen.
3. Go to the plugin settings page.
4. Enable protection and set a global password.

== Frequently Asked Questions ==

= Is this a membership plugin? =

No. It is a simple global password gate for visitors.

= Does it replace proper authentication for sensitive data? =

No. It is intended for simple access restriction, not for highly sensitive information.
